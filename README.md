# FreeBook !

**Comparte. Descubre. Lee.**

## Descripción del proyecto

FreeBook es una biblioteca virtual donde cualquier persona puede compartir libros digitales en formato PDF y descubrir nuevas lecturas.

La plataforma busca crear un espacio accesible para los amantes de la lectura, donde puedan encontrar diferentes libros, explorar categorías y contribuir compartiendo contenido con otros usuarios.

## Objetivo

Desarrollar una plataforma web que facilite el intercambio y descubrimiento de libros digitales, promoviendo el acceso a la lectura y la colaboración entre usuarios.

## Funcionalidades principales

- Compartir libros en formato PDF.
- Explorar los libros disponibles en la plataforma.
- Buscar publicaciones por título o autor.
- Consultar información y descripciones de los libros.
- Organizar los libros por categorías.
- Descargar los libros disponibles.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git y GitHub
